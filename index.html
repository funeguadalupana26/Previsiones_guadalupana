/** * ============================================================================ * FUNERALES GUADALUPANA — Backend de Contratos a Previsión * ============================================================================ * Este script se pega en el editor de Apps Script de tu Google Sheet * (Extensiones > Apps Script) y se publica como "Aplicación web". * Sirve como API para el HTML alojado en GitHub Pages. * * HOJAS QUE DEBE TENER EL SHEET (mismos nombres que tu dashboard actual): * - "Registro Contratos" * - "Control de Pagos" * - "Dashboard General" (no se toca, solo usa fórmulas para leer las otras) * * CONFIGURA ANTES DE PUBLICAR: * 1. Corre la función `configurarPinInicial` UNA VEZ desde el editor * (Ejecutar > configurarPinInicial) para fijar tu PIN de 4 dígitos. * 2. Publica: Implementar > Nueva implementación > Aplicación web * - Ejecutar como: Yo (tu cuenta) * - Quién tiene acceso: Cualquier usuario * 3. Copia la URL que te da (".../exec") y pégala en CONFIG.APPS_SCRIPT_URL * dentro de index.html. * ============================================================================ */ const HOJA_CONTRATOS = 'Registro Contratos'; const HOJA_PAGOS = 'Control de Pagos'; const HOJA_DASHBOARD = 'Dashboard General'; // Encabezados esperados (en este orden) en "Registro Contratos" const COLS_CONTRATOS = [ 'Folio Contrato', 'Fecha Contrato', 'Nombre del Cliente', 'Domicilio', 'Teléfono', 'Correo Electrónico', 'Beneficiario', 'Modalidad', 'Paquete', 'Precio Total ($)', 'Enganche ($)', 'Saldo Pendiente ($)', 'Plazo', 'Número de Pagos', 'Monto por Pago ($)', 'Estatus', 'Productos Adicionales' ]; // Encabezados esperados en "Control de Pagos" const COLS_PAGOS = [ 'Folio Contrato', 'Nombre del Cliente', 'Fecha Abono', 'Monto Abonado ($)', 'Método de Pago', 'Total Pagado a la Fecha ($)', 'Saldo Restante ($)', 'Estado Cobranza' ]; /** Ejecuta esto UNA sola vez desde el editor para fijar el PIN. */ function configurarPinInicial() { const pin = '1234'; // <-- CAMBIA este valor por tu PIN real antes de correrlo PropertiesService.getScriptProperties().setProperty('APP_PIN', pin); Logger.log('PIN configurado correctamente.'); } function doGet(e) { try { const action = e.parameter.action; if (action === 'listarContratos') { return jsonOut({ ok: true, data: listarContratos() }); } if (action === 'generarFolio') { const modalidad = e.parameter.modalidad || 'PREV'; return jsonOut({ ok: true, folio: generarFolio(modalidad) }); } return jsonOut({ ok: false, error: 'Acción GET no reconocida' }); } catch (err) { return jsonOut({ ok: false, error: String(err) }); } } function doPost(e) { try { const body = JSON.parse(e.postData.contents); const action = body.action; if (action === 'login') return jsonOut(login(body.pin)); if (action === 'guardarContrato') return jsonOut(guardarContrato(body.contrato)); if (action === 'guardarAbono') return jsonOut(guardarAbono(body.abono)); if (action === 'generarFolio') return jsonOut({ ok: true, folio: generarFolio(body.modalidad || 'PREV') }); return jsonOut({ ok: false, error: 'Acción POST no reconocida' }); } catch (err) { return jsonOut({ ok: false, error: String(err) }); } } function jsonOut(obj) { return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } function login(pin) { const real = PropertiesService.getScriptProperties().getProperty('APP_PIN') || '1234'; if (String(pin) === String(real)) { return { ok: true, token: Utilities.getUuid() }; } return { ok: false, error: 'PIN incorrecto' }; } function getSheet(nombre) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sh = ss.getSheetByName(nombre); if (!sh) throw new Error('No se encontró la hoja: ' + nombre); return sh; } /** Genera el siguiente folio con formato FG-PREV-2026-001 según el año actual. */ function generarFolio(modalidad) { const sh = getSheet(HOJA_CONTRATOS); const anio = new Date().getFullYear(); const prefijo = 'FG-PREV-' + anio + '-'; const data = sh.getDataRange().getValues(); let maxNum = 0; for (let i = 1; i < data.length; i++) { const folio = String(data[i][0] || ''); if (folio.indexOf(prefijo) === 0) { const num = parseInt(folio.substring(prefijo.length), 10); if (!isNaN(num) && num > maxNum) maxNum = num; } } const siguiente = maxNum + 1; return prefijo + String(siguiente).padStart(3, '0'); } /** Guarda un contrato nuevo y su registro inicial de enganche en Control de Pagos. */ function guardarContrato(c) { const sh = getSheet(HOJA_CONTRATOS); if (!sh.getLastRow() || sh.getLastRow() < 1) { sh.appendRow(COLS_CONTRATOS); } sh.appendRow([ c.folio, c.fecha, c.nombre, c.domicilio, c.telefono, c.correo, c.beneficiario, c.modalidad, c.paquete, c.precioTotal, c.enganche, c.saldoPendiente, c.plazoLabel, c.numeroPagos, c.montoPorPago, 'Activo', c.productosAdicionalesTexto || '' ]); // Registrar el enganche como primer abono guardarAbono({ folio: c.folio, nombre: c.nombre, fecha: c.fecha, monto: c.enganche, metodo: c.metodoEngancheInicial || 'Efectivo', esEnganche: true }, false); // false = no reajustar de nuevo el saldo del contrato (ya viene calculado) return { ok: true, folio: c.folio }; } /** Agrega un abono y actualiza el saldo pendiente + estatus del contrato. */ function guardarAbono(a, actualizarSaldoContrato) { if (actualizarSaldoContrato === undefined) actualizarSaldoContrato = true; const shPagos = getSheet(HOJA_PAGOS); if (!shPagos.getLastRow() || shPagos.getLastRow() < 1) { shPagos.appendRow(COLS_PAGOS); } const shContratos = getSheet(HOJA_CONTRATOS); const data = shContratos.getDataRange().getValues(); let fila = -1; let saldoActual = 0; let nombre = a.nombre || ''; for (let i = 1; i < data.length; i++) { if (String(data[i][0]) === String(a.folio)) { fila = i + 1; // índice de hoja (1-based) + encabezado saldoActual = Number(data[i][11]) || 0; nombre = data[i][2]; break; } } let nuevoSaldo = saldoActual; if (actualizarSaldoContrato && fila > -1) { nuevoSaldo = Math.max(0, saldoActual - Number(a.monto)); shContratos.getRange(fila, 12).setValue(nuevoSaldo); // col 12 = Saldo Pendiente if (nuevoSaldo <= 0) { shContratos.getRange(fila, 16).setValue('Liquidado'); // col 16 = Estatus } } // Total pagado a la fecha para este folio (suma de todos los abonos + este) const pagosData = shPagos.getDataRange().getValues(); let totalPrevio = 0; for (let i = 1; i < pagosData.length; i++) { if (String(pagosData[i][0]) === String(a.folio)) { totalPrevio += Number(pagosData[i][3]) || 0; } } const totalPagado = totalPrevio + Number(a.monto); shPagos.appendRow([ a.folio, nombre, a.fecha, a.monto, a.metodo, totalPagado, nuevoSaldo, nuevoSaldo <= 0 ? 'Liquidado' : 'Al Día' ]); return { ok: true, saldoPendiente: nuevoSaldo, totalPagado: totalPagado }; } /** Devuelve todos los contratos como lista de objetos, para buscar folios en el front-end. */ function listarContratos() { const sh = getSheet(HOJA_CONTRATOS); const data = sh.getDataRange().getValues(); const out = []; for (let i = 1; i < data.length; i++) { if (!data[i][0]) continue; out.push({ folio: data[i][0], fecha: data[i][1], nombre: data[i][2], domicilio: data[i][3], telefono: data[i][4], correo: data[i][5], beneficiario: data[i][6], modalidad: data[i][7], paquete: data[i][8], precioTotal: data[i][9], enganche: data[i][10], saldoPendiente: data[i][11], plazoLabel: data[i][12], numeroPagos: data[i][13], montoPorPago: data[i][14], estatus: data[i][15], productosAdicionales: data[i][16] || '' }); } return out; } /** * ============================================================================ * INICIALIZAR / REPARAR LA ESTRUCTURA DEL LIBRO (hojas y encabezados) * ============================================================================ * Corre esto UNA vez para armar el libro desde cero, o cada vez que quieras * verificar/reparar la estructura: menú "Funerales Guadalupana" en la hoja * de cálculo → "Verificar / reparar estructura del libro" (o desde el * editor: Ejecutar > crearEstructuraCompleta). * * Qué hace: * 1. Crea "Registro Contratos" y "Control de Pagos" si no existen. * 2. Escribe/corrige la fila 1 (encabezados) EXACTAMENTE en el orden que * usan guardarContrato / guardarAbono / listarContratos — así los * encabezados salen siempre de la misma fuente que usa el código y * nunca vuelven a quedar invertidos, incompletos o desalineados. * 3. Da formato a los encabezados (negritas, fondo, fila congelada), ajusta * anchos de columna, y aplica formato de moneda/fecha a las columnas * que corresponden. * 4. Agrega listas desplegables (Modalidad, Estatus, Método de Pago, * Estado de Cobranza) para evitar captura manual inconsistente. * 5. Reconstruye "Dashboard General" con fórmulas en vivo que leen * directamente de las otras 2 hojas — nunca se llena a mano. * * IMPORTANTE si la hoja ya tiene datos capturados: * - Esta función NUNCA borra filas de datos (fila 2 en adelante) de * "Registro Contratos" ni "Control de Pagos" — solo corrige la fila 1. * - Si tus datos actuales ya estaban capturados en columnas equivocadas, * corregir el encabezado los etiqueta correctamente pero no los mueve * de columna. En ese caso, respalda/exporta lo que tengas y considera * empezar con hojas limpias. * - "Dashboard General" SÍ se reconstruye por completo cada vez que corres * esta función (se borra y se vuelve a armar), porque solo contiene * fórmulas — nunca captura manual. * ============================================================================ */ function crearEstructuraCompleta() { const shContratos = asegurarHojaConEncabezados_(HOJA_CONTRATOS, COLS_CONTRATOS); const shPagos = asegurarHojaConEncabezados_(HOJA_PAGOS, COLS_PAGOS); aplicarFormatoColumnas_(shContratos, COLS_CONTRATOS, ['Precio Total ($)', 'Enganche ($)', 'Saldo Pendiente ($)', 'Monto por Pago ($)'], ['Fecha Contrato']); aplicarFormatoColumnas_(shPagos, COLS_PAGOS, ['Monto Abonado ($)', 'Total Pagado a la Fecha ($)', 'Saldo Restante ($)'], ['Fecha Abono']); aplicarListaDesplegable_(shContratos, COLS_CONTRATOS.indexOf('Modalidad') + 1, ['Cremación', 'Inhumación']); aplicarListaDesplegable_(shContratos, COLS_CONTRATOS.indexOf('Estatus') + 1, ['Activo', 'Liquidado', 'Cancelado']); aplicarListaDesplegable_(shPagos, COLS_PAGOS.indexOf('Método de Pago') + 1, ['Efectivo', 'Transferencia', 'Tarjeta', 'Depósito']); aplicarListaDesplegable_(shPagos, COLS_PAGOS.indexOf('Estado Cobranza') + 1, ['Al Día', 'Atrasado', 'Liquidado']); construirDashboardGeneral_(); SpreadsheetApp.getActiveSpreadsheet().toast( 'Hojas y encabezados verificados/creados correctamente.', 'Funerales Guadalupana', 6 ); } /** Crea la hoja si no existe y (re)escribe su fila 1 con los encabezados correctos. */ function asegurarHojaConEncabezados_(nombreHoja, encabezados) { const ss = SpreadsheetApp.getActiveSpreadsheet(); let sh = ss.getSheetByName(nombreHoja); if (!sh) sh = ss.insertSheet(nombreHoja); sh.getRange(1, 1, 1, encabezados.length).setValues([encabezados]); // Si quedaron columnas de más a la derecha con encabezados viejos, se limpian. const colsActuales = sh.getMaxColumns(); if (colsActuales > encabezados.length) { sh.getRange(1, encabezados.length + 1, 1, colsActuales - encabezados.length).clearContent(); } sh.getRange(1, 1, 1, encabezados.length) .setFontWeight('bold') .setBackground('#2f3e37') .setFontColor('#ffffff') .setHorizontalAlignment('center') .setVerticalAlignment('middle') .setWrap(true); sh.setFrozenRows(1); sh.autoResizeColumns(1, encabezados.length); return sh; } /** Aplica formato de moneda y fecha a las columnas que correspondan, por nombre de encabezado. */ function aplicarFormatoColumnas_(sh, encabezados, nombresMoneda, nombresFecha) { const MAX_FILAS = 2000; nombresMoneda.forEach((nombre) => { const col = encabezados.indexOf(nombre) + 1; if (col > 0) sh.getRange(2, col, MAX_FILAS, 1).setNumberFormat('$#,##0.00'); }); nombresFecha.forEach((nombre) => { const col = encabezados.indexOf(nombre) + 1; if (col > 0) sh.getRange(2, col, MAX_FILAS, 1).setNumberFormat('dd/mm/yyyy'); }); } /** Agrega una lista desplegable (sin bloquear valores fuera de lista, por si el script escribe otro). */ function aplicarListaDesplegable_(sh, columna, opciones) { if (columna <= 0) return; const MAX_FILAS = 2000; const regla = SpreadsheetApp.newDataValidation() .requireValueInList(opciones, true) .setAllowInvalid(true) .build(); sh.getRange(2, columna, MAX_FILAS, 1).setDataValidation(regla); } /** Convierte un número de columna (1, 2, 3...) a su letra de columna (A, B, C...). */ function columnaLetra_(col) { let letra = ''; while (col > 0) { const resto = (col - 1) % 26; letra = String.fromCharCode(65 + resto) + letra; col = Math.floor((col - 1) / 26); } return letra; } /** Reconstruye "Dashboard General" con fórmulas en vivo (se borra y se vuelve a armar). */ function construirDashboardGeneral_() { const ss = SpreadsheetApp.getActiveSpreadsheet(); let sh = ss.getSheetByName(HOJA_DASHBOARD); if (!sh) sh = ss.insertSheet(HOJA_DASHBOARD); else sh.clear(); const colC = (nombre) => columnaLetra_(COLS_CONTRATOS.indexOf(nombre) + 1); const colP = (nombre) => columnaLetra_(COLS_PAGOS.indexOf(nombre) + 1); const rFolio = `'${HOJA_CONTRATOS}'!${colC('Folio Contrato')}2:${colC('Folio Contrato')}`; const rEstatus = `'${HOJA_CONTRATOS}'!${colC('Estatus')}2:${colC('Estatus')}`; const rModalidad = `'${HOJA_CONTRATOS}'!${colC('Modalidad')}2:${colC('Modalidad')}`; const rPrecioTotal = `'${HOJA_CONTRATOS}'!${colC('Precio Total ($)')}2:${colC('Precio Total ($)')}`; const rSaldoPendiente = `'${HOJA_CONTRATOS}'!${colC('Saldo Pendiente ($)')}2:${colC('Saldo Pendiente ($)')}`; const rMontoAbonado = `'${HOJA_PAGOS}'!${colP('Monto Abonado ($)')}2:${colP('Monto Abonado ($)')}`; const rFechaAbono = `'${HOJA_PAGOS}'!${colP('Fecha Abono')}2:${colP('Fecha Abono')}`; const rEstadoCobranza = `'${HOJA_PAGOS}'!${colP('Estado Cobranza')}2:${colP('Estado Cobranza')}`; sh.getRange('A1').setValue('DASHBOARD GENERAL — Funerales Guadalupana') .setFontWeight('bold').setFontSize(14); sh.getRange('A2').setValue('Esta hoja se actualiza sola con fórmulas — no captures datos aquí a mano.') .setFontStyle('italic').setFontColor('#888888'); const filas = [ ['CONTRATOS', ''], ['Contratos totales', `=COUNTA(${rFolio})`], ['Activos', `=COUNTIF(${rEstatus},"Activo")`], ['Liquidados', `=COUNTIF(${rEstatus},"Liquidado")`], ['Cancelados', `=COUNTIF(${rEstatus},"Cancelado")`], ['', ''], ['POR MODALIDAD', ''], ['Cremación', `=COUNTIF(${rModalidad},"Cremación")`], ['Inhumación', `=COUNTIF(${rModalidad},"Inhumación")`], ['', ''], ['DINERO', ''], ['Valor total contratado', `=SUM(${rPrecioTotal})`], ['Saldo pendiente por cobrar', `=SUM(${rSaldoPendiente})`], ['Total abonado histórico', `=SUM(${rMontoAbonado})`], ['Abonado este mes', `=SUMIFS(${rMontoAbonado},${rFechaAbono},">="&EOMONTH(TODAY(),-1)+1,${rFechaAbono},"<="&EOMONTH(TODAY(),0))`], ['', ''], ['COBRANZA', ''], ['Contratos en mora / atrasados', `=COUNTIF(${rEstadoCobranza},"Atrasado")`] ]; sh.getRange(4, 1, filas.length, 2).setValues(filas); // Formato: subtítulos de sección en negritas, montos con formato de moneda ['A4', 'A10', 'A14', 'A20'].forEach((celda) => sh.getRange(celda).setFontWeight('bold').setBackground('#efead9')); sh.getRange(4, 1, filas.length, 1).setFontWeight('bold'); sh.getRange('B14:B18').setNumberFormat('$#,##0.00'); sh.setColumnWidth(1, 260); sh.setColumnWidth(2, 160); sh.setTabColor('#c7a862'); } /** Menú propio en la hoja de cálculo para correr la verificación con un clic. */ function onOpen() { SpreadsheetApp.getUi() .createMenu('Funerales Guadalupana') .addItem('Verificar / reparar estructura del libro', 'crearEstructuraCompleta') .addToUi(); }
